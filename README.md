# Music Player

A vanilla HTML, CSS and JavaScript music player built for the
[devChallenges Music Player challenge](https://devchallenges.io/challenge/music-player).

## Features

- Play / pause the current song
- Next and previous song (wraps around the playlist)
- Seekable progress bar with current time and duration
- Auto-advances to the next song when one ends
- Responsive layout, including short landscape screens
- Keyboard accessible (Tab to controls, arrow keys on the progress bar)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
